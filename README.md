# Python_CLIexpenseTraker
a command line interface python based project including python fundamentals and json concepts on the beginner level to implement   

💰 Python CLI Expense Tracker

A simple command-line Expense Tracker built with Python. It allows users to add, view, filter, delete expenses, and calculate total spending. Data is stored locally in a JSON file.

🚀 Features

Add expense

View all expenses

View total expense

Filter by category

Delete expense

Data saved in expenses.json

▶️ Run the Project
python expense_tracker.py
